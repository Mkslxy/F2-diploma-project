# РОЗДІЛ 2. АРХІТЕКТУРНЕ ТА АЛГОРИТМІЧНЕ ПРОЄКТУВАННЯ СИСТЕМИ

## 2.1. Архітектурне моделювання за підходом C4 Model
- Рівень Context: взаємодія системи із зовнішніми акторами та інтеграціями.
- Рівень Container: поділ на клієнтський додаток (Next.js/React), API-шлюз (Django REST Framework) та сховище даних (Firebase/PostgreSQL).
- Рівень Component: внутрішня декомпозиція модуля балансування навантаження.

## 2.2. Комплект UML-діаграм поведінки та структури
- Діаграма прецедентів (Use Case Diagram) із розмежуванням ролей (RBAC).
- Діаграми послідовності (Sequence Diagrams) для сценаріїв запису пацієнта та диспетчеризації слотів.

## 2.3. Алгоритмічне забезпечення модуля оптимізації завантаженості
- Математична постановка задачі балансування тайм-слотів прийому спеціалістів.
- Алгоритм евристичного розподілу навантаження та усунення колізій черги.
