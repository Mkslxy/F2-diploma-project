# РОЗДІЛ 1. АНАЛІТИЧНИЙ ОГЛЯД ПРЕДМЕТНОЇ ОБЛАСТІ ТА ФОРМУВАННЯ ВИМОГ ДО СИСТЕМИ

## 1.1. Аналіз сучасних підходів до автоматизації управління медичними центрами
- Огляд архітектур існуючих медичних інформаційних систем (МІС).
- Порівняльний аналіз рішень-аналогів за критеріями пропускної здатності, затримок обробки та відмовостійкості.

## 1.2. Формалізація інженерної проблеми та обмежень
- Виявлення вузьких місць традиційних монолітних підходів до планування прийомів.
- Ризики втрати даних та простою спеціалістів при пікових навантаженнях.

## 1.3. Специфікація функціональних та нефункціональних вимог (SRS)
- Функціональні вимоги до модуля диспетчеризації та балансування завантаженості.
- Нефункціональні вимоги згідно з ДСТУ: Latency, Fault Tolerance, сумісність за протоколами REST API.
